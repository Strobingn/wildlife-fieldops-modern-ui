# Batch 6 self-check

Version `2.6.0-batch6`. No new Supabase SQL. Fine-grained fields sync inside the existing `jobs.pricing` jsonb column through AutoSync (Room writes on `jobs`, `customers`, `inspections`, and `photos`). Live `jobs.status` still uses only `Active`, `Scheduled`, `In Progress`, `Needs Follow-up`, `Closed`, and `Cancelled`. The pipeline name is stored in `pricing.pipelineStatus` and wins on pull.
